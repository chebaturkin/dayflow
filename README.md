# dayflow

небольшой local-first план дня: занятия можно менять прямо в браузере, отменённые не попадают в итог, а активные выгружаются в календарь как ICS.

## запуск

```bash
npm install
npm run dev
```

## что внутри

- редактируемый список занятий;
- сохранение в браузере;
- светлая и тёмная тема;
- экспорт отдельного занятия в ICS;
- тесты логики расписания и календарного файла.

данные никуда не отправляются. dayflow не связан с каким-либо вузом или расписанием.
