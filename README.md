# dayflow

dayflow превращает расписание в аккуратную картинку, которой удобно поделиться. Можно отправить подробный план или показать только свободные окна — без доступа к календарю, аккаунта и передачи данных в сеть.

![светлая тема](public/preview-light.png)

![тёмная тема](public/preview-dark.png)

## запуск

```bash
npm install
npm run dev
```

## проверка и сборка

```bash
npm test
npm run build
```

`npm test` запускает тесты расписания и экспорта в ICS. `npm run build` проверяет проект и создаёт готовую сборку в `dist/`.

чтобы посмотреть собранную версию локально:

```bash
npm run preview
```

## что внутри

- два режима карточки: план с названиями и доступность с анонимными блоками «занято / свободно»;
- автоматический расчёт свободных окон и предупреждение о пересечениях;
- редактируемые события, заметки, статусы «по плану / перенесли / отменили»;
- дата и подпись дня, три спокойных оформления, светлая и тёмная тема;
- PNG с датой и выбранным режимом;
- ICS для отдельного события или всего дня;
- JSON для резервной копии и переноса между браузерами;
- локальное хранение без сервера и аккаунта.

dayflow не связан с каким-либо вузом или расписанием. Данные остаются в браузере, пока вы сами не экспортируете файл.

## зачем

Календарь хорошо подходит для себя, но им неудобно делиться: он раскрывает названия событий и просит дать доступ к личному аккаунту. dayflow делает маленький самостоятельный артефакт — красивый план или приватный ответ на вопрос «когда ты свободен?».
