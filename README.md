# dayflow

dayflow собирает план дня в одну понятную картинку. Можно показать расписание целиком или только время, когда вы свободны. Данные остаются в браузере — без регистрации и доступа к календарю.

![светлая тема](public/preview-light.png)

![тёмная тема](public/preview-dark.png)

## запуск

```bash
npm install
npm run dev
```

## проверка и сборка

```bash
npm test
npm run build
```

`npm test` запускает тесты расписания и экспорта в ICS. `npm run build` проверяет проект и создаёт готовую сборку в `dist/`.

чтобы посмотреть собранную версию локально:

```bash
npm run preview
```

## что внутри

- два режима карточки: план с названиями и свободное время без названий событий;
- автоматический расчёт свободных окон и предупреждение о пересечениях;
- редактируемые события, заметки, статусы «по плану / перенесено / отменено»;
- дата и название дня, три спокойных оформления, светлая и тёмная тема;
- PNG с датой и выбранным режимом;
- ICS для отдельного события или всего дня;
- JSON для резервной копии и переноса между браузерами;
- данные хранятся в браузере; сервер и аккаунт не нужны.

В демо используются вымышленные события. Данные остаются в браузере, пока вы сами не экспортируете файл.

## зачем

Календарь удобен для себя, но им сложно делиться: он раскрывает названия событий и просит открыть доступ к аккаунту. dayflow превращает расписание в одну понятную картинку — полный план или только свободное время.
