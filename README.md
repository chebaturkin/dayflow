# dayflow

соберите план дня и сохраните его одной понятной картинкой. можно показать расписание целиком или оставить только свободное время — без регистрации, календарного доступа и сервера.

[открыть dayflow](https://chebaturkin.github.io/dayflow/)

## зачем

календарь удобен для себя, но им неловко делиться: в нём видны названия встреч и личные детали, а для просмотра иногда нужен доступ к аккаунту. dayflow оставляет расписание в браузере и превращает его в карточку, которую можно отправить отдельно.

## что умеет

- два вида карточки: план с названиями событий и свободное время без них;
- расчёт свободных окон и предупреждение, если события пересекаются;
- дата, название дня, заметки и статусы «по плану», «перенесено» и «отменено»;
- три спокойных оформления, светлая и тёмная тема;
- PNG для карточки, ICS для календаря и JSON для резервной копии;
- локальное хранение: данные не уходят из браузера, пока вы сами не скачаете файл.

в демо стоят вымышленные события. их можно заменить своими или начать с пустого листа.

## как запустить локально

нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

откройте адрес из терминала. изменения применяются сразу.

## как проверить сборку

```bash
npm test
npm run build
```

`npm test` проверяет расчёт расписания, импорт JSON и экспорт в ICS. `npm run build` запускает `astro check` и собирает статическую версию в `dist/`.

для просмотра готовой сборки:

```bash
npm run preview
```
