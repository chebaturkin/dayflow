# dayflow

расписание на день, которым удобно поделиться картинкой или текстом. запишите дела и добавьте заметки. если названия встреч лучше оставить при себе, покажите только занятое и свободное время.

[открыть dayflow](https://chebaturkin.github.io/dayflow/?lang=ru)

![dayflow: расписание и готовая карточка в светлой теме](public/preview-light.png)

## что можно сделать

- собрать план с датой, названием дня, заметками и статусами событий;
- показать расписание целиком или скрыть названия и оставить свободное время;
- сохранить картинку в одном из трёх оформлений или скопировать текст для сообщения;
- добавить следующее событие сразу после последнего дела;
- отменить правку, удаление или замену расписания, затем повторить действие;
- скачать события для календаря в ics, сохранить расписание в json и открыть его позже;
- выключить подпись dayflow на карточке;
- работать со светлой или тёмной темой, с компьютера или телефона.

свободными считаются промежутки от 30 минут между событиями. пересекающиеся встречи подсвечиваются, а занятое время считается без повторов. отменённые события остаются в редакторе и не попадают в карточку.

## как пользоваться

выберите дату и напишите название дня, если оно нужно. замените пример своими делами или начните с пустого листа. время вводится в формате `09:30`; можно набрать `0930`, двоеточие появится само.

справа выберите, чем поделиться: планом или свободным временем. затем сохраните картинку или скопируйте текст. меню «файл» открывает и сохраняет расписание, скачивает события для календаря и возвращает пример.

`ctrl / ⌘ + enter` добавляет событие. `ctrl / ⌘ + z` отменяет изменение, `ctrl / ⌘ + shift + z` повторяет его. внутри текстового поля работает привычная отмена ввода; для отмены всего действия есть кнопки рядом с меню «файл».

## где хранятся данные

регистрация и доступ к календарю не нужны. расписание сохраняется в браузере на этом устройстве и не отправляется на сервер. для переноса на другой компьютер скачайте json через меню «файл».

если очистить данные браузера, локальное расписание пропадёт. перед очисткой сохраните копию. в примерах стоят вымышленные события.

## язык

интерфейс, новые примеры и подписи экспорта доступны на русском и английском. язык можно выбрать через `ru / en` в шапке. сначала учитывается корректный `?lang=ru` или `?lang=en` в ссылке, затем сохранённый выбор, первый поддерживаемый язык браузера и английский как запасной.

переключение сохраняет названия, заметки, даты и незавершённый ввод времени. уже сохранённые записи остаются как написаны.

## запуск

нужен node.js 20 или новее. установите версии зависимостей из lock-файла:

```bash
npm ci
npm run dev
```

откройте [локальное приложение](http://127.0.0.1:4321/dayflow/?lang=ru). если порт 4321 занят, терминал покажет другой адрес.

## проверка

```bash
npm test
npm run build
```

модульные тесты проверяют расчёты, пересечения, историю изменений, текстовый экспорт, импорт json, экспорт ics и выбор языка. сборка включает проверку типов и создаёт статический сайт в `dist/`.

для браузерных проверок нужен python с playwright и установленным chromium. запустите сайт через `npm run dev`, затем в другом терминале:

```bash
python3 tests/browser-check.py
python3 tests/layout-check.py
python3 tests/language-check.py
```

проверки проходят основные действия, экспорт, сохранение незавершённых правок при смене языка и раскладку от 320 до 1440 пикселей. переменная `DAYFLOW_URL` позволяет проверить другой адрес.

на скриншотах выше вымышленные события и русская версия интерфейса. чтобы обновить русские и английские снимки из работающего приложения:

```bash
python3 tests/capture-languages.py
```

## публикация

изменения в `main` автоматически собираются и публикуются через github actions на [github pages](https://chebaturkin.github.io/dayflow/?lang=ru).
