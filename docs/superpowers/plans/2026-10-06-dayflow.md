# dayflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** build a polished local-first daily schedule that exports a day card and calendar events.

**Architecture:** Astro serves a static shell. Small TypeScript modules own the schedule model, browser storage, ICS serialization and UI rendering; the UI never sends schedule data to a server.

**Tech Stack:** Astro, TypeScript, Vitest, browser Canvas API, localStorage.

---
